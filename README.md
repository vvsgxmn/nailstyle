# 基于SpringBoot+Vue的美甲预约系统

![Spring Boot](https://img.shields.io/badge/-Spring%20Boot-6DB33F?style=flat-square&logo=spring-boot&logoColor=white) ![Vue3](https://img.shields.io/badge/-Vue3-grey?style=flat-square) ![ElementPlus](https://img.shields.io/badge/-ElementPlus-grey?style=flat-square) ![MySQL](https://img.shields.io/badge/-MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white) 

## 项目介绍

一个完整的美甲预约管理系统，用户可以浏览美甲款式、按分类和标签筛选、查看款式详情并在线预约美甲服务；管理员可以在后台管理款式、预约订单、分类标签、轮播图等，并查看数据统计。

## 功能模块

- **美甲款式管理**：支持按分类、标签、价格筛选，展示款式图片、价格、浏览量等信息
- **在线预约**：用户选择款式、日期、时间段后提交预约，自动填充联系信息
- **预约管理**：管理员可查看、确认、完成或取消预约订单
- **分类管理**：对美甲款式进行分类（简约、法式、日系、显白等）
- **标签管理**：为款式添加多标签（简约、温柔、可爱、优雅等）
- **轮播图管理**：首页Banner图配置与管理
- **数据统计**：预约趋势图、热门款式排行、各状态预约数量统计
- **用户中心**：个人信息管理、头像修改

## 技术架构

- **后端**：Spring Boot 2.6.13 + MyBatis 2.2.2 + JWT认证 + PageHelper分页
- **前端**：Vue 3.5 + Element Plus 2.4 + Vite 7 + ECharts 5.4 + Pinia
- **数据库**：MySQL 8.0
